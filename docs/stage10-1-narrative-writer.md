# Stage 10.1：隔离 Narrative Writer

本轮仅进行工程修复、官方配置核实和 Mock 测试。未发起真实模型请求，未修改
历史数据、数据库 Schema、README 或个人计划。Stage 10 的 Synthesis 继续选择

## 模型与费用审核（2026-10-27）

[官方模型与定价](https://api-docs.deepseek.com/quick_start/pricing/)列明
`deepseek-flash` 对应 `DeepSeek-V4.1-Flash-1017`，上下文为 1M，最大输出为 384K，
支持 JSON 输出。不是根据本地别名推测容量。
[Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)
确认 `/chat/completions`、`response_format=json_object`、`max_tokens` 和
`thinking.type=disabled`。JSON 模式不是语义真实性或严格业务 Schema 保证。

新增独立审核配置 `MODEL_REVIEW`，限定官方 HTTPS 主机和文档所列模型；7 天后
返回 BLOCKED，需重新审核。它不修改全项目缺失的环境费率，也不拿默认价格当作
任意供应商报价。此入口的峰时非缓存费率明确为输入 $0.30 / 百万 tokens、
输出 $1.20 / 百万 tokens；不假设缓存命中或非高峰折扣。

最坏费用 = 16,000 × 0.30 / 1,000,000 + 4,000 × 1.20 / 1,000,000
= **US$0.0096**。请求前预留完整 20,000 tokens 和 9,600 micro-USD，
限额为 US$0.50；未知模型、过期审核、费率不一致或预算不足一律先拒绝。
应用内预留不是供应商 Usage，也不是最终账单。真实调用前仍应确认费率未变。

## 输出契约与证据约束

`domain/narrative.py` 从可信 matrix 重建阅读模型，不信任调用者提供的 presentation。
输入目录中的论点保留原 Fact / Finding / Evidence 映射。模型只处理执行摘要、
产品定位、差异分析及结论；矩阵、定价表、证据原文、研究局限、PARTIAL 状态不变。
请求只传这些章节所需的论点和证据；整个历史 matrix 的 17 条事实及 17 条证据
仍保留在报告中，并未为了压缩请求删除或改写原始数据。

结构化响应包含文档摘要、section ID、paragraphs，以及每段的 claim_ids、
variant_ids、evidence_ids、text。每条原论点必须在所属章节出现一次，不能删除
信息缺口、交换产品引用或将某章节的论点移到别处。可组合 1–3 条论点为一段。

为避免“合法引用旁夹带新断言”，本版采用有限转述语法：模型可选择原表达或经
审核的等价措辞替换，例如“定位为”→“官方定位是”；段落正文必须与选中表达
逐字一致，只允许换行组合。引用要求精确匹配这些论点的证据并集；渲染时仍逐条
插入引用。价格、优势、无来源结论即便使用正确 Evidence ID 也无法通过正文检查。
输入中的引用文本始终是数据；输出不会执行工具或指令。

这能验证有限表达空间内的改写与组织，**不能验证任意自由转述的语义真实性**。
不在词表中的合理改写也会被拒绝；不宣称能够发现所有幻觉。源事实与词表自身的
语义正确性仍依赖既有事实验证和人工规则审阅。Mock 成功不等于真实模型自然度达标。

## 适配与隔离

`NarrativeWriter` 复用已有 `BudgetedSession`、`CostRates`、`TaskBudget` 和
`ResearchContext` 工厂，使用相同 DeepSeek Chat Completions 协议；不更改 Synthesis
的输出契约。计费分类沿用 synthesis，独立上下文中只允许 1 次模型请求。
搜索、抓取、提取、理解和评估预算全为零。没有工具声明，没有自动重试或重定向。
HTTP adapter 若启用重试则拒绝请求。

输入沿用现有传输层的保守文本上界：完整请求 JSON 的 UTF-8 字节数加 1,024
framing 余量，不使用字符到 token 的平均比例。超过 16,000 即拒绝；输出显式
设为 4,000，关闭 thinking，不发送图片或文件。该上界针对当前文本接口，
不是对未来 tokenizer、额外工具或其他模型的保证；模型/协议变化需重审。

内存锁和独占创建的本地 attempt 文件共同阻止并发、异常后重试和进程重启后的
重复调用。一个已授权实验必须始终使用同一 attempt 文件；不能改路径绕过授权。
标记先于请求创建，异常不退款，不自动清除。原始响应仅保留在 provider 对象及
明确的本地验收文件中，密钥回显会拒绝保存。超时、HTTP 失败、超长响应、错误 JSON、
截断及语义校验失败均保留规则报告，不以失败的模型正文代替正式内容。

`scripts/replay_narrative_writer.py` 是**仅 Mock**的离线命令，没有 live 参数。
通过注入 session 验证真正的请求构造与响应处理，使用虚拟密钥，生成新目录中的
请求、Mock 原始输出、验证后阅读 JSON、中文 Markdown 和审计记录。真实資料只在
忽略的本地 build 目录，不加入 Git。下一次实时验收仍须另行授权。

## 验证范围

合成测试覆盖合法转述与组合、错误引用/引用错配、虚构价格、优势断言、无来源
结论、遗漏边界、跨章节错配、重复论点、超长输入/输出、错误 JSON、超时、HTTP
异常、截断、预算不足、审核过期、未授权、重复调用和安全回退。另使用本地历史
Run #38 验证 17 条事实、17 条证据保持不变，报告仍为 PARTIAL。
私有 Fixture 不提交；其他环境缺少此文件时仅跳过这一历史回放测试。

最终验证：完整非付费回归 **652 passed**（新增 23 项），无跳过或失败；唯一警告
是既有 Starlette/httpx 弃用提示。本地 Run #38 Mock 请求保守输入上界为 7,026，
输出设置为 4,000；模拟账本预留 20,000 tokens / US$0.0096，真实调用与真实费用
预留均为零。原始输入未变，模型实际 Usage 尚不存在。

具备下一次**受限转述与组织**的单次真实模型测试入口。它尚不支持把任意自由
中文正文自动认定为可信报告。真实语言质量、指令遵循率和供应商 Usage 必须等
下一次单独授权后才能评价；本轮不执行。
